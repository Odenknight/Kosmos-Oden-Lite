## Feature/functionality state now (v1.0.6)

- **Vendored-core, patches-only**: this plugin **vendors** a copy of the GKOS
  Engine's source directly into `src/core/` rather than depending on it as a
  package. It does not consume `gkos-engine` as a dependency at all. Policy is
  patches-only on the `1.0.x` line forever — no new engine features get pulled
  in, only backported bug fixes.
- **Drift-check CI** (`scripts/check-core-drift.mjs`, wired into
  `npm run check:core-drift`): on every CI run, clones the real GKOS Engine at
  the parity tag declared in `package.json` (`"engineParity": "v1.0.7"`),
  diffs it against the vendored copy, and fails on any unexplained difference.
  A small allowlist (`scripts/core-drift-allowlist.json`) records the six
  intentional deltas (product identity, the `tool:kosmos-oden` assessor, a
  widened sensitivity export, and minor doc/import-order noise) with reasons
  and fingerprints, so future drift is caught but known/reviewed differences
  don't false-positive.
- **Fail-closed sensitivity + twelve-state epistemic handling**: backported
  from the engine (DIV-001/002/003) — notes with no sensitivity fail closed
  to `secret`, out-of-vocabulary epistemic states project to `unknown` with a
  detectable marker, and naive timestamps get flagged.
- **Package identity**: npm package name is `kosmos-oden-lite` (renamed from
  `kosmos-oden`, which collided with the full Kosmos-Oden product name). The
  Obsidian plugin id itself stays `vault-kosmos-oden` — unchanged deliberately
  so existing installs don't break.
- **VERSIONING.md**: documents the patches-only policy and points to the
  canonical policy home in `gkos-standard`.
